# BloomCode lab

Jupyter notebooks for the Python tracks of [BloomCode](https://bloomcode.github.io/): one notebook per chapter, with the same
exercises and tests as the [dsa-python](https://github.com/bloomcode/dsa-python) and
[cp-python](https://github.com/bloomcode/cp-python) starters. Each exercise links to its explanation in the workbook and to
a tested solution in the answer key.

## Use it

- **In the browser:** open a notebook in Colab from the tables below. Nothing to install.
- **On your machine:** `pip install jupyterlab pytest`, clone this repo, and run `jupyter lab`.

In each notebook, run the setup cell once. Then, for every exercise, replace the stub in its code cell, run it, and run the
test cell underneath. Your work stays in your own copy: in Colab, use **File → Save a copy in Drive**.

Prefer an editor, `git push` and a progress badge? Use the starters instead; the exercises are the same.
